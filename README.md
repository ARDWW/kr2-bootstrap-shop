## Описание проекта
Многостраничный сайт магазина настольных игр. Предметная область та же, что и в КР №1, но сайт написан заново на Bootstrap.
В проекте четыре страницы: главная, каталог с фильтром, страница товара и форма заявки.

## Используемый фреймворк
Bootstrap 5.3.8.

## Способ подключения Bootstrap
Bootstrap подключён **через CDN** (jsDelivr). CSS стоит в `<head>`, а `css/custom.css` подключён после него, чтобы переопределять стили.
JS-бандл `bootstrap.bundle.min.js` подключён перед `</body>`: он нужен для меню, модального окна, аккордеона, вкладок, карусели и toast.

Чтобы перейти на **локальное подключение**, запустите `python use_local.py`. Скрипт скачает файлы в `vendor/bootstrap/`
(`css/bootstrap.min.css` и `js/bootstrap.bundle.min.js`) и заменит ссылки во всех html-файлах.
После этого нужно изменить этот раздел README: «Bootstrap подключён локально из папки `vendor/bootstrap/`».

## Самостоятельные доработки
- Каталог: поиск (input-group), фильтр по категории (form-select) и цене, пагинация по 6 карточек, сообщение alert при пустом результате.
- Страница товара собирается по параметру `?id=` из `js/products.js`, поэтому одна страница показывает все 8 игр. Есть счётчик количества (input-group), вкладки (tabs), таблица характеристик.
- Счётчик корзины в navbar хранится в `localStorage`, при добавлении товара появляется toast.
- Форма заявки: валидация Bootstrap (`was-validated`), радиокнопки доставки, выбранный товар подставляется со страницы товара, после отправки показывается alert.
- Карусель акций, аккордеон FAQ, хлебные крошки.
- В `custom.css` кнопка `btn-brand` сделана через CSS-переменные Bootstrap, фон hero нарисован через `conic-gradient`, настроены шрифты и цвета через `--bs-*`.
- Адаптивность: карточки в 1, 2, 3 и 4 колонки (`col-12 col-sm-6 col-lg-4 col-xl-3`), форма и фильтры перестраиваются на узких экранах.
- Скрипт `use_local.py` для перехода на локальный Bootstrap.

## Как проверить
1. Открыть `index.html` в браузере (нужен интернет для CDN и шрифтов).
2. В DevTools (F12) включить режим устройств и проверить ширины 360, 768, 1200 px.
3. На мобильной ширине нажать «бургер» и убедиться, что меню раскрывается.
4. Нажать «Задать вопрос»: открывается modal, форма проверяется, окно закрывается.
5. В каталоге ввести «азул», выбрать категорию, задать цену, проверить пагинацию.
6. На странице заявки отправить пустую форму (появятся подсказки), затем заполнить и отправить (появится alert).
